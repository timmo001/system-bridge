System Bridge runs on your computer and shares what it's doing, such as CPU, memory, disks, media and Discord, with the [web client](/using/web-client), [Home Assistant](/using/home-assistant), the [CLI](/using/cli) and your own code. It can also control your computer: play and pause media, show notifications, run commands you choose, and more.

## What it reports

| Module | What's in it |
| --- | --- |
| System | Hostname, platform, uptime, users, and which apps are using the camera or microphone |
| Processes | Running processes with their CPU and memory use |
| CPU | Usage, frequency, temperature and each core's load |
| Memory | Physical memory and swap |
| GPUs | Load, memory, clocks, temperature and power |
| Sensors | Temperatures and fan speeds |
| Battery | Charge, charging state and time remaining |
| Displays | Resolution, position and refresh rate |
| Disks | Partitions, space and activity |
| Networks | Interfaces, addresses, traffic and connections |
| Media | What's playing and its position |
| Discord | Your voice state and call |

See [Monitoring](/features/monitoring) for every way to read them.
